- `style.css` — estilos
- `script.js` — destaque do menu ativo ao rolar a página

## Adicionar sua foto

Coloque um arquivo chamado **`foto.jpg`** na mesma pasta destes arquivos
(idealmente uma imagem quadrada, algo como 300x300px ou maior).
O `index.html` já referencia `src="foto.jpg"` — assim que o arquivo existir
no repositório, a foto aparece automaticamente no lugar do quadro "AB".

Se o arquivo não for encontrado, a página mostra as iniciais "AB" no lugar,
sem quebrar o layout.
